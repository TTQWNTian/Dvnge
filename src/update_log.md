# Dvnge 更新日志

## v1.10.0-dev
### 新增
- 新增 `限制游戏视口` 配置，可锁定游戏显示区域，支持 `px`、`%`、`vw`、`vh`、`dvh`、`svh` 等 CSS 单位
- 新增 `历史记录系统`，玩家可查看已读对话，支持回退到任意历史节点
- 新增 `历史记录配置`，可配置是否启用、最大条数、是否允许回退、回退后是否清除后续
- 新增 `@模式 NVL` 与 `@模式 ADV`，可在剧本中切换连续文本模式与传统对话框模式
- 存档快照新增显示模式与 NVL 文本累积状态，旧存档默认使用 ADV 模式

### 修改
- 游戏内容统一包裹进 `#游戏视口`，所有游戏内定位从 `fixed` 改为 `absolute`
- 存档界面与历史记录界面共用 `.全屏界面` 样式
- 历史记录界面与存档界面共用 `.标题` 和 `.关闭按钮` 样式
- 移除 `@音乐淡出` 指令，淡出时长统一由 `@音乐` 的 `淡出` 参数控制
- 将引擎脚本拆分为多个独立文件，并通过 `js/引擎/index.js` 按顺序加载
- 新增 `js/main.js`，统一负责加载游戏配置、引擎、工具和自定义脚本，并在模块加载完成后初始化引擎
- 移除 `js/引擎/初始化.js` 中自动启动引擎的代码，改由主入口统一启动，避免初始化时序冲突

### 修复
- `@音乐` 的 `淡出` 参数未生效的问题
- 选项 `条件` 不满足时不隐藏选项的问题
- 标题容器连续切换时 `class` 与行内样式累积的问题
